# WarEra continuation: verified public contracts

Checked 2026-10-12 with **15 anonymous, read-only GET requests** to the [WarEra tRPC API](https://api2.warera.io/docs/). The metadata-only [probe record](artifacts/probes/continuation.json) contains status codes, keys, kinds and small counts; it contains no entity IDs, complete profiles, article text, or credentials. The [WarEraProjects Python client](https://github.com/WarEraProjects/api-client-py) was used to identify candidate procedure names and inputs. WarEraProjects describes itself as a community project, not the game operator; live API responses below are the contract evidence. The official documentation page currently exposes no extractable schema in this environment.

| Area | Anonymous contract observed | Safe interpretation and next module |
| --- | --- | --- |
| Player relations and activity | `user.getUserById({userId})` returned `party`, `company`, `mu`, `country`, `dates.lastConnectionAt`, level/XP, damage/wealth stats. `party.getById({partyId})` returned `leader`, `councilMembers`, `members`. `mu.getById({muId})` returned member IDs and `roles.managers`/`roles.commanders`. | A sourced **current** relationship graph and activity snapshots are feasible. Select only needed fields: the full user response also exposed unrelated `preferences`, `emailVerified` and other fields. Do not retain the full profile or claim historical membership before WINT first observes it. [User client](https://raw.githubusercontent.com/WarEraProjects/api-client-py/main/warera/resources/user.py), [unit model](https://raw.githubusercontent.com/WarEraProjects/api-client-py/main/warera/models/military_unit.py). |
| Unit member activity | `muMember.getByMu({muId})` returned an array with `user`, `mu`, total/monthly/weekly damage and help counts, plus timestamps. | Unit member cards and **observed** activity changes can be built; these are aggregate counters, not per-battle participation. [Client method](https://raw.githubusercontent.com/WarEraProjects/api-client-py/main/warera/resources/mu_member.py). |
| Elections and government | `election.getElections({countryId,limit:2})` returned a page containing `items` and `nextCursor`. A country-free election request returned HTTP 500. | A country-scoped election archive, results, current government and political chronology are feasible. Verify pagination and more countries before calling it a complete global history. Do not depend on a global election listing. [Election client](https://raw.githubusercontent.com/WarEraProjects/api-client-py/main/warera/resources/election.py), [model](https://raw.githubusercontent.com/WarEraProjects/api-client-py/main/warera/models/election.py). |

Mere absence from the feed is not proof of completion. Per-player or per-unit battle rankings remain an **unverified** candidate via `battleRanking.getRanking`. [Battle client](https://raw.githubusercontent.com/WarEraProjects/api-client-py/main/warera/resources/battle.py). |

No worker detail list was observed. | A public company directory and owner link are now **available**, so the old “unverified” source classification can be revised after implementation. This does not establish access to private finances, wages, individual workers or every possible company field. [Company client](https://raw.githubusercontent.com/WarEraProjects/api-client-py/main/warera/resources/company.py), [model](https://raw.githubusercontent.com/WarEraProjects/api-client-py/main/warera/models/company.py). |

[Region model](https://raw.githubusercontent.com/WarEraProjects/api-client-py/main/warera/models/region.py). |

## Still unverified or restricted

- **Article comments and public chat:** no live contract was established in this capped probe. The reviewed [client resource list](https://github.com/WarEraProjects/api-client-py/tree/main/warera/resources) does not document a comment or chat resource. Absence from a community client does not prove no API exists. Keep these sources disabled until an official public, authorized contract is verified. Do not collect private chats or Discord channels without permission.
- **Article content rights:** the existing article feed includes `content`, including items marked `isPublic:false`; WINT correctly strips bodies and excludes unknown/private visibility. The official [WarEra terms page](https://app.warera.io/terms) did not provide extractable permission text here. Public API access alone is not evidence of redistribution or large-scale text-processing rights. Continue metadata-only search and source links; request written permission before full-text archives or AI summaries of bodies.
- **Membership history, company private fields, map polygons and exact per-battle member damage:** current responses support snapshots or limited aggregates, not past states or these unobserved contracts. Label them unverified, not auth-blocked. The observed HTTP 500 on country-free elections is an endpoint error, not proof of an authentication requirement.
